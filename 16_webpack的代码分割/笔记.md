## 代码分离
- 将代码分离到不同bundle中，**按需加载，并行加载**
- 所有代码在首页全部加载，影响首屏速度
- 代码分离出更小的bundle，控制资源加载优先级，提高代码加载性能

## 分离手段
- 使用entry配置手动分离代码   entry配置多个入口，output [name].bundle.js
- 防止重复  entryDependencies SplitChunks plugin 
- 动态导入  通过模块的内联函数调用来分离代码

webpack默认配置的optimization代码分割只是对异步加载的方式进行分包
```
// ⭐ 默认不会自动帮你拆 vendors（注意！）
  splitChunks: {
    chunks: 'async' // 只拆动态 import
  },
```

webpack 不管设置怎么样，动态导入都会分包
动态导入包的名字，一般叫chunk,通过chunkFilename,然后通过魔法注释，类似router，在前面加上注释
